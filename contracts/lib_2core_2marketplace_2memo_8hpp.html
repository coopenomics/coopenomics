Подробное описание

Человекочитаемые memo для marketplace ledger2-операций.

Аналог Capital::Memo (см. cpp/capital/domain/entities/memo.hpp). Текст memo попадает в журнал ledger2 (поле journal.memo) и в выписки пайщика / отчёт бухгалтеру — это пользовательский слой, поэтому никаких технических токенов ("p.mkt.supply", "L6", op_code) здесь быть не должно.

Параметризуется значимыми идентификаторами (id Order'а) — для трассировки в выписке без необходимости резолвить hash через backend.
