void Marketplace::Dues::note_return (eosio::name coopname, const order &o, const eosio::asset &cost, const eosio::asset &fee)
 Гарантийный возврат принят: стоимость возвращённого и его обеспечительная часть снимаются со счётчиков периода заказа. Строки нет — обеспечительная часть по заказу уже списана по итогу периода, и возврат с кошелька к списанию невозможен: отказ с кодом, решение совета не исполняется. Счётчик участка поправляется, пока итог периода не рассчитан; после расчёта ставки зафиксированы, списание строки пайщика идёт по ним на уменьшенные суммы. Подробнее...
