Подробное описание

Паевые взносы инициаторов одного кооперативного участка и счётчик возврата (CRPS). Строка заводится первым паевым взносом и живёт, пока у участка есть инициаторы.

Обозначения: единицы инициатора units_i = used_money_i + property_i (использованный паевой взнос), база base = Σ units_i по инициаторам в статусе active, возвращено инициатору returned_i = returned_fixed_i + units_i × (acc − acc_join_i) / SCALE. Суммы s_join = Σ units_i × acc_join_i и s_fixed = Σ returned_fixed_i по базе дают непогашенный остаток участка за O(1): base − s_fixed − (acc × base − s_join) / SCALE.
