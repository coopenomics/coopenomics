    Interface PrivateData

    Приватный payload транспортной накладной (ТТН).

    Хранится off-chain в коллекции doc_private_data фабрики; on-chain публикуется только doc_data_hash. Содержимое — персональные данные экспедитора и параметры физической перевозки, которые недопустимо публиковать в блокчейн. См. раздел «Document Generation Pattern: doc_data» в архитектуре.
