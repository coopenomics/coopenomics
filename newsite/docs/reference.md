# Справочники

Машинные референсы: они не рассказывают, а **отвечают на точный вопрос** —
как называется метод, какие у него поля, что лежит в таблице контракта.
Каждый собирается автоматически из исходников при выпуске релиза, поэтому
всегда соответствует опубликованной версии.
