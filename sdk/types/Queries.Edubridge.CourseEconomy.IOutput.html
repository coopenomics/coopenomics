    Экономика курса: план и факт по назначенным преподавателям

    • actual_cost_month: string

      Себестоимость месяца по ставкам назначенных преподавателей

    • actual_hours_per_month: number

      Часов в месяц, распределённых между преподавателями

    • group_fee_month: string

      Взносы участников за месяц при нынешнем числе участников

    • Optional group_id?: null | string

      Группа курса, по которой посчитан месяц

    • group_program_month: string

      Остаётся программе за месяц при нынешнем числе участников

    • group_teachers_month: string

      Взнос преподавателей за месяц при нынешнем числе участников

    • learners_active: number

      Участников группы с оплаченным доступом на сегодня

    • over_fee: boolean

      Обязательства перед преподавателями превысили собранный взнос

    • pay_per_learner: boolean

      Взнос преподавателя за занятие в группе считается за каждого участника; иначе фиксированный за занятие

      Плановый расчёт взноса

      • cost_course: string

        Себестоимость курса

      • cost_month: string

        Себестоимость месяца — часы по ставке

      • course_discount_amount: string

        Скидка за взнос разом в сумме

      • course_months: number

        Длительность курса в месяцах, с шагом в неделю (0,25); ноль — у курса нет конечной программы

      • fee_course: string

        Членский взнос за весь курс разом

      • fee_course_base: string

        Сумма помесячных взносов за весь курс

      • fee_month: string

        Членский взнос за месяц

      • hours_per_month: number

        Часов занятий в месяц

      • lessons_per_month: number

        Занятий в месяц по окнам расписания: окон недели на четыре

      • markup_month: string

        Целевой членский взнос кооператива в сумме за месяц

      • markup_percent: number

        Целевой членский взнос кооператива, проценты

      • max_course_discount_percent: number

        Предельная скидка при текущем целевом членском взносе, проценты

      • reserve_hours_per_month: number

        Из них часов резерва для внеочередных занятий в месяц

    • start_locked: boolean

      В группе проведены занятия: дата начала занятий группы не изменяется
