    Оператор отменяет заказ со склада кооператива до открытия выдачи (например, при переформировании докладки). Средства возвращаются пайщику, позиции — в остаток.

    • Optional accepted_at?: unknown

      Когда поставщик принял заказ.

    • Optional blocked_at?: unknown

      Когда средства были заблокированы.

    • Optional cancelled_at?: unknown

      Когда заказ был отменён.

    • Optional chairman_account?: null | string

      Учётная запись председателя, открывшего выдачу первой подписью.

    • Optional chairman_signed_at?: unknown

      Когда председатель кооперативного участка открыл выдачу первой подписью.

    • Optional checkout_id?: null | string

      Идентификатор заказа заказчика — общий для всех позиций одного оформления корзины на один пункт выдачи. Позволяет сгруппировать позиции в один заказ. Пусто для прежних покарточных заказов.

    • coopname: string

      Кооператив, в котором сделан заказ.

    • Optional create_tx?: {
          block_num: number;
          locked_amount: string;
          signed_at: string;
          tx_hash: string;
      }

      Снимок транзакции блокировки средств (для отображения движений кошелька).

      • block_num: number

        Номер блока, в который попала транзакция.

      • locked_amount: string

        Сумма зарезервированных средств (строка денежного актива).

      • signed_at: string

        Время подписания заказа (ISO 8601).

      • tx_hash: string

        Идентификатор транзакции в блокчейне.

    • created_at: unknown

      Когда запись о заказе создана в системе.

    • Optional current_warehouse_braname?: null | string

      Кооперативный участок, на котором имущество физически лежит к моменту выдачи.

    • Optional cycle_id?: null | string

      Идентификатор партии-накопителя, если заказ присоединён.

    • delivery_braname: string

      Имя пункта выдачи (ПВЗ), куда пайщик хочет получить заказ.

    • Optional delivery_point_address?: null | string

      Адрес пункта выдачи — для отображения вместо служебного идентификатора ПВЗ.

    • Optional delivery_point_lat?: null | number

      Широта пункта выдачи на карте — чтобы показать заказчику, куда ехать за заказом.

    • Optional delivery_point_lng?: null | number

      Долгота пункта выдачи на карте — чтобы показать заказчику, куда ехать за заказом.

    • Optional delivery_point_name?: null | string

      Наименование пункта выдачи (кооперативного участка) — для отображения вместо служебного идентификатора ПВЗ.

    • Optional delivery_signer_account?: null | string

      Учётная запись стороны кооператива, поставившей подпись вместе с заказчиком.

    • Optional group_accumulated_quantity?: null | number

      Сколько уже накоплено по этому предложению на данном пункте выдачи всеми заказчиками на этапе сбора партии (для прогресса коллективного заказа). Заполняется только пока заказ копится; после приёма поставщиком — пусто.

    • Optional group_min_volume?: null | number

      Целевой минимальный объём поставки на этот пункт выдачи — ориентир сбора партии (не жёсткий порог). Заполняется только на этапе сбора.

    • id: string

      Идентификатор заказа.

    • Optional image_url?: null | string

      Обложка товара (первое изображение предложения) — для отображения в карточке заказа.

    • is_ready_announced: boolean

      Оператор пункта выдачи объявил заказ готовым к выдаче — заказчику отправлено уведомление «приходите заберите». Пока false, заказ принят кооперативом, но ещё не готов к получению.

    • Optional issuance_fact?: {
          actual_quantity: number;
          diff_state: MarketplaceOrderIssuanceFactDiffState;
          fact_cost: string;
          fact_unit_price: string;
      }

      Фактическая выдача после финальной подписи заказчика (заполняется на ПВЗ).

      • actual_quantity: number

        Фактически выданное количество единиц.

      • diff_state: MarketplaceOrderIssuanceFactDiffState

        Сверка фактической выдачи с заказом.

      • fact_cost: string

        Фактическая стоимость выдачи (actual_quantity × фактическая цена за единицу).

      • fact_unit_price: string

        Фактическая цена за единицу (скорректирована оператором при открытии выдачи).

    • Optional last_status_reason?: null | string

      Текстовая причина последнего изменения статуса.

    • Optional membership_fee?: null | string

      Членский взнос, включённый в стоимость заказа, по ставке на момент оформления. Заказчик платит total_cost + membership_fee; пусто — заказ ещё не подтверждён блокчейном.

    • offer_hash: string

      Хеш предложения в блокчейне (snapshot на момент заказа).

    • offer_id: string

      Идентификатор предложения, по которому оформлен заказ.

    • order_hash: string

      Хеш заказа в блокчейне (для сверки).

    • orderer_account: string

      Аккаунт пайщика-заказчика.

    • Optional orderer_name?: null | string

      Наименование заказчика (ФИО пайщика или название организации) — для экранов выдачи/подписи.

    • Optional orderer_signed_at?: unknown

      Когда заказчик поставил финальную подпись на акте выдачи.

    • Optional orderer_verification_passed?: null | boolean

      Прошёл ли получатель верификацию личности, требуемую для выдачи имущества (null — вердикт не запрашивался).

    • package_size: number

      Содержимое упаковки в базовой единице (Эпик 18): 0 — отпуск по мере, иначе quantity/package_size — число упаковок в заказе.

    • price_per_unit: string

      Цена за единицу товара на момент заказа.

    • Optional product_name?: null | string

      Название товара из предложения — для отображения в карточке заказа.

    • quantity: number

      Количество единиц товара в заказе.

    • Optional received_at?: unknown

      Когда пайщик получил заказ.

    • Optional shipment_id?: null | string

      Партия поставки (shipment), в которую заказ включён при формировании. null — заказ акцептован, но в партию не вошёл. Позволяет приёмке отделить состав конкретной партии.

    • Optional signiss1_tx_hash?: null | string

      Хэш транзакции открытия выдачи в блокчейне.

    • Optional signiss2_tx_hash?: null | string

      Хэш транзакции финальной подписи выдачи в блокчейне.

    • status: MarketplaceOrderStatus

      Текущий этап жизненного цикла заказа.

    • supplier_account: string

      Аккаунт поставщика.

    • Optional supplier_name?: null | string

      Наименование поставщика (ФИО или название организации) — для экранов приёмки/подписи.

    • total_cost: string

      Общая сумма заказа (стоимость имущества без членского взноса).

    • total_cost_with_fee: string

      Полная сумма к оплате заказчиком: total_cost + membership_fee. Готовое значение — клиенту не нужно складывать поля самому.

    • Optional unit_of_measure?: null | MarketplaceUnitOfMeasure

      Базовая единица измерения товара из предложения (штука, килограмм, литр).

    • updated_at: unknown

      Когда запись о заказе последний раз изменялась.

    • Optional warehouse_arrival_price?: null | string

      Цена прибытия единицы на склад — по ней имущество принято у поставщика; null, если склад не запрашивался

    • Optional warehouse_locations?: null | string[]

      Полки склада пункта выдачи, на которых лежат позиции заказа после раскладки. Пусто — позиции ещё не размещены. Заполняется в лентах выдачи.

    • Optional warehouse_quantity?: null | number

      Сколько по заказу фактически принято на склад пункта выдачи и ещё не выдано — доступно к выдаче. Может быть меньше заказанного при недопоставке. Заполняется в лентах выдачи.

    • warranty_period_secs: number

      Срок гарантии в секундах с момента получения.

    • Optional warranty_until?: unknown

      Дата окончания гарантии.
